# How to run marisela-site-02-bold

Bold & Colorful design · generated by artist-site-factory.

## Start the site

```bash
cd generated-websites/marisela-site-02-bold
npm run dev
```

Then open **http://localhost:3001**. Dependencies (`node_modules/`) are already installed.
This site is pinned to port 3001 (`dev` and `start` scripts in package.json), so it can run alongside a site on 3000.

## Production

```bash
npm run build
npm start
```

## Notes

- Content lives in `lib/content.ts` (fetched from public sources; see README.md for provenance and licenses).
- The newsletter form is a front-end mock — connect `components/Newsletter.tsx` to your email provider before launch.
